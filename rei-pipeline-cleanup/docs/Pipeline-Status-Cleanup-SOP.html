Pipeline Status Cleanup

Standard Operating Procedure  ·  REI BlackBook Property Pipeline
Twin Home Buyer / Equity Track  ·  Version 1.1  ·  App build 0.1.1  ·  2026-07-15

1What this automation does

The Pipeline Status Cleanup app goes through the "New" bucket of the REI BlackBook Property Pipeline and sets each lead's correct status based on the rep's own work — so the pipeline reflects reality instead of everything sitting on "New."

  • Reads each lead's attached contact (the rep's Lead Stage / Call Disposition) — it follows the rep's categorization, it does not guess.
  • Sets each lead to one of four pipeline stages — New, Evaluating, Under Contract, or Closed — fully automatically (no human step).
  • Closed is used for both dead/lost and sold leads, and the bot writes a note explaining why it was closed.
  • Flags conflicting or unclear leads and duplicates with an explanatory note.
  • Cleans obvious address formatting (Street / City / ZIP). The State field is never touched.
  • Everything it does is reversible and reload-verified (it confirms each change actually saved).

2How it works — the process

Each run works the whole New bucket top-to-bottom, one lead at a time:

  1. Open the REI pipeline and load every New lead.
  2. For each lead, open its attached contact and read the latest Lead Stage / disposition and activity.
  3. Decide the correct status from that signal (see the rules in section 3).
  4. Write the status, then reload and verify it stuck (retry if not).
  5. Write an explanatory note — why a lead was Closed (dead/sold) or put Under Contract, and for flagged / duplicate leads (skips if the same note already exists).
  6. Tidy the address formatting where safe; leave the State field alone.
  7. Save progress (checkpoint) and move to the next lead.
Safe & resumable. If the connection drops or the app is closed, it picks up where it left off — no lead is lost or double-processed.

3The four pipeline stages

Every lead is set to one of four stages, taken from the rep's own Lead Stage — fully automatic, no human step:

StageWhen the attached contact shows…What the bot does
New (leave)No notes and no contact — nobody has touched the leadLeft as-is
EvaluatingAny contact made / analysis started — called, texted, emailed, offer being worked, comps runSet Market Status → Follow up
Under ContractA signed contract / accepted offer is notedSet Market Status → Under Contract
ClosedDeal closed or dead — per the noteSet Market Status → Closed + a note saying why (dead / lost / sold)
Also handled automatically: Duplicates (same address) are flagged with a note — never merged or deleted. Conflicting or unclear leads (e.g. a dead stage plus a later re-inquiry, or outreach logged with no Lead Stage) are left unchanged and flagged with an explanatory note for a person to look at.
Closed = dead OR sold. Both land in the Closed stage; the automation writes a note on each one stating the reason, so you can tell a dead lead from a sold property at a glance.

4Daily operating procedure

  1. Open the Pipeline Status Cleanup app (Desktop or Start Menu icon).
  2. If it's the first run of the day, make sure you're logged into REI in the Chrome window it opens.
  3. (Optional) Run once in Audit mode to preview — nothing is written.
  4. Switch Mode → Live and click Start.
  5. Let it run the full bucket. Watch the clock and the stat cards.
  6. When it finishes, open Report → Save as PDF for the daily summary.
  7. Spot-check a few leads in REI (a Follow up, a Dead) and confirm the State field is unchanged.

It runs the whole backlog each day and re-runs the next day for the new shift's leads.

5How to use — on the local PC

  1. Double-click the Pipeline Status Cleanup icon (house + green check).
  2. The app opens in its own window (toolbar, stat cards, run clock).
  3. Pick Audit (read-only) or Live (writes), then Start.
  4. Keep the window open while it runs; close it (or Stop) to end.
Team view on office Wi-Fi. While it's running, the app shows a "Share on this Wi-Fi" link with a Copy button. Teammates on the same network open that URL in a browser to watch progress and the daily report — no install needed.

6How to use — remotely via AnyDesk

The automation must run on the office PC that stays logged into REI. Use AnyDesk to reach that PC from anywhere.

  1. On the office PC: keep it powered on, signed in, and AnyDesk running. Note its AnyDesk ID (9-digit number).
  2. On your PC: open AnyDesk, type the office PC's AnyDesk ID in "Remote Desk", click Connect.
  3. Enter the access password (or accept the prompt on the office side).
  4. You now see the office desktop. Double-click the Pipeline Status Cleanup app and run it as in section 5.
  5. When done you can disconnect AnyDesk — the app keeps running on the office PC.
Important: AnyDesk is a remote view of the office PC — the automation and the REI login always run on that office PC, not on your local machine. Don't shut the office PC down while a run is in progress.

7Dashboard & daily report

  • Stat cards — Reviewed, Follow up, Dead, Under Contract, Flagged, Duplicates. Click any card to see those leads with links into REI.
  • Run clock — shows how long the automation has been running.
  • Daily Report — a clean one-page summary (plain-English + the key numbers) that you Save as PDF for records/management.

8Limitations & safety

  • State field is never changed — "CA" cannot be set in the app. REI's State dropdown only stores full names ("California"); there is no "CA" option, so the browser automation cannot produce the "CA" abbreviation. Storing literal "CA" (and filling blank states) requires the REI BlackBook API — a separate one-time pass, outside this app. Until then, the State field is left exactly as-is.
  • Addresses on leads with a contact can't be re-formatted in the UI (REI reverts them) — these are flagged for a later CSV/API pass. Leads without a contact are cleaned normally.
  • Duplicates are flagged, never merged or deleted — a person makes the final merge decision.
  • Closed covers dead and sold — both use the "Closed" status; the reason (dead / lost / sold) is written in a note on each lead.
  • Everything is reversible and every write is reload-verified (each change is confirmed after a reload; it retries if it didn't stick).

11Rebuild the app & share it online with teammates

This produces a single Setup installer that bundles everything (app + Electron + ffmpeg.dll + dependencies). Teammates download that one file, run it, and the app installs like any normal program.

Build the installer (on a Windows PC with Node.js)

  1. Open PowerShell in the project folder:
    cd C:\Users\<you>\Documents\Pipe-Automation\rei-pipeline-cleanup
  2. Get the latest code:
    git pull origin claude/pipeline-status-cleanup-test-61hwcr
  3. Run the one-command builder:
    powershell -ExecutionPolicy Bypass -File .\Build-Installer.ps1
    (or manually: npm install then npm run dist)
  4. When it finishes, the installer is in the dist folder:
    dist\Pipeline Status Cleanup Setup 0.1.1.exe

Share it online

  1. Upload that Setup .exe to Google Drive (or your shared drive).
  2. Right-click the file → Share → set "Anyone with the link" → Copy link.
  3. Send teammates the link. They download it, double-click, and install.
  4. On first launch each person logs into REI once in the Chrome window it opens.
